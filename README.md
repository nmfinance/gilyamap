# Москва и москвичи — карта Гиляровского

Интерактивная карта по книге В. А. Гиляровского: **186 адресов**, у каждого — история, цитата из книги и старая фотография с pastvu. Плюс 4 пеших маршрута и 2 исторические трассы.

Живая версия: **https://nmfinance.github.io/gilyamap/**

## Состав

| Файл | Что делает |
|---|---|
| `index.html` | вся карта целиком: данные, стили, логика. Одним файлом, без сборки |
| `manifest.json` | описание PWA — имя, иконки, цвета. Нужен для «Добавить на главный экран» |
| `sw.js` | Service Worker: кэширует оболочку, просмотренные тайлы и фото → карта работает офлайн |
| `icons/` | иконки приложения 192/512 + apple-touch-icon |

## Как выложить (один раз)

1. Залить все файлы **с сохранением папки `icons/`** в корень репозитория `nmfinance/gilyamap`.
2. `Settings` → `Pages` → Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)** → Save.
3. Через 1–2 минуты сайт поднимется по адресу выше.

Через веб-интерфейс GitHub: `Add file` → `Upload files` → перетащить `index.html`, `manifest.json`, `sw.js` и **папку `icons`** целиком.

## Про токен Mapbox

Токен вшит в `index.html` — так и должно быть, публичный токен (`pk.…`) для того и существует. Но его обязательно нужно ограничить по адресу, иначе чужой сайт сможет тратить вашу квоту:

Mapbox → **Account** → **Access tokens** → нужный токен → **URL restrictions** → `Add URL`:

```
https://nmfinance.github.io/*
```

⚠️ После установки ограничения карта **перестанет работать при открытии файла двойным кликом** (протокол `file://`) — это нормально и ожидаемо. Проверять локально можно так:

```bash
cd папка_с_файлами
python3 -m http.server 8000
# открыть http://localhost:8000
```

и временно добавить в URL restrictions ещё и `http://localhost:8000/*`.

Если Mapbox станет недоступен (кончилась квота, отозван токен, нет сети) — карта **сама переключится на OpenStreetMap**, это заложено в коде.

## Как поменять стиль подложки

В `index.html` найти строку:

```js
const MAPBOX_STYLE  = 'mapbox/streets-v12';
```

Варианты: `mapbox/light-v11` (светлый, ближе к старой бумаге), `mapbox/outdoors-v12`, `mapbox/satellite-streets-v12`. Поверх любой подложки наложен сепия-фильтр из CSS (`.leaflet-tile-pane`).

## После правок

Если меняли `index.html`, в `sw.js` поднимите версию, иначе у тех, кто уже открывал карту, останется старая из кэша:

```js
const VERSION = 'v2';   // было v1
```

## Установка как приложение

- **iPhone (Safari):** «Поделиться» → «На экран „Домой“»
- **Android (Chrome):** ⋮ → «Установить приложение» / «Добавить на главный экран»

Кнопка **📍** в правом нижнем углу — «Где я?»: центрирует карту на текущем положении и рисует круг точности.
